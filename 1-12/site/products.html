Процессоры

Центральные процессоры (CPU) - это мозг вашего компьютера. Мы предлагаем процессоры от ведущих производителей:

Топовые модели процессоров:

  1. Intel Core i9-13900K
  2. AMD Ryzen 9 7950X
  3. Intel Core i7-13700K
  4. AMD Ryzen 7 7800X3D

Критерии выбора процессора:

  • Количество ядер
    • Для офисных задач: 2-4 ядра
    • Для игр: 6-8 ядер
    • Для профессиональных задач: 8+ ядер
  • Тактовая частота
  • Техпроцесс
  • Тепловыделение (TDP)

Материнские платы

Материнские платы - основа любой сборки ПК, определяющая совместимость компонентов:

Форм-факторы материнских плат:

  • ATX - стандартный размер
    • Максимальное количество слотов
    • Лучшее охлаждение
  • Micro-ATX - компактный вариант
  • Mini-ITX - для мини-ПК

Сокеты для процессоров:

  1. LGA 1700 - для Intel 12th-13th Gen
  2. AM5 - для AMD Ryzen 7000
  3. AM4 - для AMD Ryzen 3000-5000
